JSON 图鉴

JSON（JavaScript Object Notation）是前后端数据交换的通用文本格式

1 JSON 长什么样


        
    
            
  • 键必须用双引号：JSON 里没有单引号，"name" 合法，'name' 不合法。
    • 
            
  • 支持的数据类型：字符串、数字、布尔（true/false）、null、数组、对象。
    • 
            
  • 不支持函数、undefined、注释；字符串也必须用双引号。
    • 
            
  • 键值对之间用逗号分隔，最后一个键值对后面不能有逗号。
    •

4 什么时候用 JSON

        
    
            
  • 接口通信：fetch 拿到的响应通过 response.json() 直接解析成 JS 对象。
    • 
            
  • 本地存储：localStorage 只能存字符串，对象需先 stringify，取出时再 parse。
    • 
            
  • 配置文件：package.json、VS Code 配置等都采用 JSON 格式。
