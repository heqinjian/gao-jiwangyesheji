Font Awesome 图标演示

Font Awesome 是典型的字体图标方案：图标被打包成 woff2 字体文件，通过 @font-face 加载， HTML 中用 <i class="fa-solid fa-xxx"> 引用，本质是一个字符，可像文字一样设置颜色、大小、行高。 本页所有资源均本地化于 cdn/fontawesome/（css + woff2）。

① 三种字体风格 fa-solid / fa-regular / fa-brands

Font Awesome Free 提供三套字体：实心（solid）、线框（regular）、品牌（brands）。三者是不同字体文件，靠类名切换。

fa-solid 实心
fa-regular 线框
fa-brands 品牌

要点：同一图标的 solid 与 regular 共用名字 fa-heart，但风格类不同；品牌图标只有 brands 一套。

② 尺寸缩放 fa-2x ~ fa-5x

字体图标是字符，直接用 font-size 控制大小，FA 也提供 fa-2x…fa-5x 倍数类，fa-fw 固定等宽对齐。

1x
2x
3x
4x
5x

要点：矢量字体任意缩放不失真；列表中混用不同图标时加 fa-fw（fixed width）可保证文字对齐。

③ 颜色控制 color

字体图标没有"填充色"概念，直接用 CSS color 改色，也可继承父元素颜色。

red
orange
yellow
green
blue
purple

要点：图标颜色走 currentColor，父级设 color 即可整体变色，与文字主题天然统一。

④ 旋转与翻转 fa-rotate / fa-flip

工具类可直接对字符做旋转、镜像：fa-rotate-90/180/270、fa-flip-horizontal/vertical。

原始
rotate-90
rotate-180
flip-h
flip-v

要点：需要任意角度时用 transform: rotate(35deg)；工具类只提供固定档位。

⑤ 内置动画 fa-spin / fa-pulse / fa-beat

FA 6 内置旋转、脉冲、心跳、弹跳、抖动、淡入六种动画类，纯 CSS 实现，加载与下载场景最常用。

fa-spin 加载
fa-pulse 步进
fa-beat 心跳
fa-bounce 弹跳
fa-shake 抖动
fa-fade 淡入

要点：旋转动画等价于 animation: fa-spin 2s linear infinite；尊重系统「减少动态效果」设置时可用 @media (prefers-reduced-motion) 关闭。

⑥ 图标堆叠 fa-stack

用 fa-stack 容器 + fa-stack-1x/2x 把两个字符叠放，可组合出"角标"、"禁止"等复合图标。

circle + flag
comment + ban
square + terminal
