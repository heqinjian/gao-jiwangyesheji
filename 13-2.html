Lucide SVG 图标演示

Lucide 是SVG 图标方案：每个图标是一段 <svg> 矢量代码，直接内联到 HTML 中。 线条用 stroke="currentColor" 绘制，颜色、粗细、描边动画都可以用 CSS 精确控制，且不需要加载任何字体文件。 原始 SVG 文件存放于 cdn/lucide/icons/（lucide-static v0.469.0）。

① 尺寸控制 width/height 或 1em

给 SVG 设 width:1em; height:1em 后，图标大小就跟随 font-size，与字体图标用法一致；也可以直接给像素值。

16px
24px
32px
48px

要点：所有 Lucide 图标都基于 viewBox="0 0 24 24"，等比缩放不会变形，也不会像字体那样出现基线偏移。

② 描边粗细 stroke-width

图标是线条画，可用 CSS stroke-width 调节线宽（1 / 2 / 3），这是字体图标完全做不到的能力。

stroke-width: 1
stroke-width: 2（默认）
stroke-width: 3

要点：端点样式由 stroke-linecap="round"、拐角由 stroke-linejoin="round" 控制，Lucide 已内置。

③ 颜色控制 currentColor

线条默认 stroke="currentColor"，给父级或 SVG 设 color 即可变色；需要实心时再改 fill。

④ CSS 动画 transform / stroke-dasharray

SVG 元素本身可直接参与 CSS transform 动画；利用 stroke-dasharray 还能做「线条描边生长」效果。

旋转
摇摆
心跳
漂浮
断网抖动
描边生长 dasharray

要点：旋转/摇摆要设 transform-origin（如铃铛顶部）；描边生长的 dasharray 长度需按路径周长调整。

⑤ 交互：悬停填充与按钮 fill + transition

悬停时把心形从描边切换为实心，以及与文字组合的图标按钮，都是 SVG 最常见的 UI 用法。

SVG 方案的优缺点：多色、描边、fill、独立动画都可控，按图标加载无冗余；缺点是内联图标会增加 HTML 体积、不利于整图缓存， 超大图标库（数百个）通常配合 SVG sprite（<use href="#id">）或 JS 动态注入使用。
