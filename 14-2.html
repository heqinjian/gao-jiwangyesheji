易踩坑与补充

            
    
                
  • typeof null === "object"：这是 JavaScript 的历史遗留 Bug，null 本身仍是基本类型，判空请用 x === null。
    • 
                
  • undefined vs null：undefined 表示「声明了但未赋值」，由系统产生；null 表示「人为置空」，需要主动赋值。
    • 
                
  • NaN：属于 number 类型，且 NaN 不等于任何值（包括它自己），用 isNaN() / Number.isNaN() 判断。
    • 
                
  • Symbol：ES6 新增，每个 Symbol 值都独一无二，常用作对象的唯一属性名，防止键名冲突。
    • 
                
  • BigInt：ES2020 新增的第 7 种原始类型（数字后加 n，如 123n），用于安全表示任意大整数。
    • 
                
  • 除基本类型外，Object（对象）为引用类型，Array、Function 本质上也都是对象。
